# Ukrainian coin artwork — v0.22.0

Shared denomination-side renderer for 1, 2, 5, 10, 25, 50 kopiyok and 1 hryvnia. Materials come from the existing catalogue (including aluminum/steel 2 kopiyok). Hryvnia before 2004 uses the old denomination/wreath composition; later gold and silver issues use the denomination, year and scroll ornament composition. Portrait sides and mint die micro-varieties are not reproduced. All artwork is schematic, not a replica.

References: https://bank.gov.ua/ua/uah/obig-coin and the catalogue source URLs stored on each item; 25-kopiyok specimen references in art-025.md.

Inventory, collection, detail previews and excavation use one painter. Existing IDs, rarity, prices and save format are unchanged. Checks: gameplay and backup suites, native Canvas comparison of ten design/material combinations, live collection dialogs.
