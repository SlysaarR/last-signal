# 25-kopiyok artwork — v0.21.0

Original procedural Canvas rendition of the reverse, shared by excavation, inventory and collection. Conditions 20, 60 and 95 can be compared in the coin detail dialog. The game condition scale is not a numismatic grade. Die varieties are not reproduced.

Reference specimens:
- https://museum.mincult.gov.ua/collections/moneta-25-kopiyok-1992-r-125364
- https://commons.wikimedia.org/wiki/File:Ukraine-25-kopiyok-1992.jpg

No reference photo is shipped. Stable seeded grain, scratches and patina avoid random changes during redraws. Catalog IDs, rarity, prices and save format remain unchanged.

Validation: existing gameplay/save/backup regression suite; native Canvas rendering at three conditions; live collection dialog inspection.
