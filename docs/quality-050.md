# Перевірка 0.50.0 — Перші кроки

2026-10-14. Це крок до релізу 1.0, не магазинний кандидат. Повні критерії й відкриті питання — у [release-1.0.md](release-1.0.md).

## Поведінка

Пропозиція короткого навчання з’являється для початкового стану в таборі. До явного ввімкнення чи приховування підказок стан гри не змінюється. Старий прогрес не отримує нових обов’язкових полів або автоматичного модального вікна.

Чотири етапи: виїзд → забрана знахідка → повернення → підтверджений альбом або продаж. Порожня яма, залишена знахідка й скасований продаж не завершують відповідний етап. У разі раннього повернення можна вирушити ще раз; жодна конкретна монета чи виплата не потрібна. Металобрухт також підходить, тому навчання не залежить від рідкісної здобичі.

`guide` — необов’язкове поле `{version:1,enabled:boolean,stage:0..4}`. Етап записується в тій самій транзакції збереження, що й дія. При прихованих підказках виконані дії також враховуються. Перезапуск, JSON-копія та відновлення зберігають етап; некоректний формат відхиляється без перезапису вихідних даних. Підказки не видають додаткових предметів, купонів чи досвіду.

«Як грати» доступне з верхньої панелі. Діалог містить пояснення основного циклу, керування дотиком/мишею/клавіатурою, запасів, кар’єри та резервного копіювання. Пошук і фон погоди за відкритим довідником призупинено. Розкопку/рішення про предмет треба завершити перед відкриттям довідника, як і для інших меню.

## Перевірки й оптимізація

Усі **25 наборів `npm run check` успішні**. Новий `guide-check.cjs` перевіряє реальний шлях від натискання кнопки навчання до продажу, скасування дороги, залишену знахідку, відновлення незавершеної розкопки, завантаження в таборі, JSON-копію, приховування/повернення/повторення, старі сейви, пошкоджені дані, пакетний альбом/продаж лише після підтвердження.

Контрольний і навчальний виїзди з однаковим seed мають ідентичні **всі** ігрові дані, крім необов’язкового `guide`. Поточні 222 ID, ціни, 27 покупок спорядження, ґрунт, погода, кар’єра, замовлення, збережені ділянки та офлайн перевіряються попередніми наборами.

Навчання не додає таймерів, анімацій або RAF-циклів. Картка оновлює DOM лише при зміні свого змісту, рух котушки її не перемальовує. 50 повторних відкриттів довідника/рендерів не споживають RNG і не створюють кадрів. Нові кнопки мають видимий фокус, підказки/довідник — назви для допоміжних технологій. Перевірено унікальність HTML ID і єдину версію URL кожного JS-модуля, щоб не створити два екземпляри стану в браузері.

Повторно підтверджено відому проблему програмного 3D-огляду: бубонець на native Canvas 300×250, п’ять ракурсів, 335–378 мс/кадр. Випробуване звуження області затінення не усунуло проблему й до версії не включене. Геометрія й рендер цієї версії збережені; окреме полегшення fallback залишається пріоритетом до 1.0. Це локальний CPU-замір, а не показник GPU або фізичного телефона.

Офлайн-пакет: **128 ресурсів, 3,37 МіБ**, release hash `f65ee7430374ca64`. Картка, довідник і стан навчання доступні офлайн; нових зовнішніх запитів немає.

## Права та межі готовності

`npm run audit:assets` перевірив відповідність усіх 42 фото їхнім джерелам і SHA-256: помилок інвентаризації немає, усі права позначені як невирішені. `node scripts/audit-assets.mjs --strict` очікувано відмовляє в магазинному релізі. Наявність джерела не прирівняно до дозволу. Нові фото не додавалися, контакти з власниками не здійснювалися.

Workflow **Game quality** запускає регресії та інвентаризацію матеріалів для main і PR. Він не встановлює branch protection і не заміняє тестування збірки чи перевірку прав.

Візуальне компонування нового довідника, перший запуск сторонньою людиною, жести, звук, читач екрана та реальні FPS на Android/ПК **ще не перевірені**. У цьому середовищі браузерний QA недоступний. Нативних APK/AAB/Windows-збірок і підтвердження магазинів немає.
