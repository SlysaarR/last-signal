# Перевірка якості 0.32.0

Дата: 13.10.2026. Базова версія: 0.31.0, коміт 9ea44d49333ce4596fb21d45e33921163988ee75.

## Зміни

- Полотно картки знахідки тепер має узгоджені внутрішні й CSS-пропорції 600×500. Підпис знаходиться у звичайному потоці, кнопка початкового ракурсу — поза зображенням.
- Перемикання трьох картинок замінено обертанням об’ємної геометрії по двох осях. Монета має окремі передню й задню текстури та гурт. Геометрія є також для решти наявних форм предметів.
- Один спільний WebGL-контекст використовує перевірку глибини, освітлення та згладжені нормалі. Текстури й буфер перевикористовуються під час жесту. Якщо WebGL недоступний або контекст втрачено, працює Canvas-рендер тієї самої геометрії зі спрощеним освітленням.
- Дефекти поверхні залежать від стану без категорій чи стрибка на 40% / 100%. Їхні координати стабільні для виду предмета; стан змінює силу, розмір та видимість дефектів. Однакові вид і стан дають однаковий малюнок, окремого випадкового візерунка кожен екземпляр не отримує.
- Повзунок стану в картці колекції керує лише зразком. Обертання та порівняння не змінюють збереження чи ціну предмета.

## Автоматичні перевірки

`npm run check` — пройдено всі п’ять наборів, включно з попередніми перевірками старих ID, імпорту, збережень, очищення, виїздів, грошей і нагород.

`tests/inspection-check.cjs` перевіряє безперервний кут, рух другим пальцем, втрату захоплення, об’єднання подій у кадр, скасування попереднього кадру при зміні предмета, незмінність даних при порівнянні, монотонний профіль усіх 101 значення стану, видимість сторін і гурту та скінченні координати всіх форм.

`tests/inspection-browser.cjs` — окрема перевірка у справжньому Chromium з локальним тестовим збереженням. Потрібні встановлений Playwright та Chromium; ігрова сторінка залежностей не отримує. Запуск:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium node tests/inspection-browser.cjs
```

Перевірено:

- Вікно отримання знахідки: 320×568, 390×844, 412×915, 844×390 — правильні пропорції, відсутність горизонтального переповнення й перекриття підпису та кнопки.
- Справжня послідовність браузерних touch-подій змінює довільний кут монети, без вибору кадру.
- Відкрита знахідка 65% переживає перезавантаження зі збереженням стану.
- Повзунок 64% → 65% змінює зразок без змін у даних гри.
- Для монети 1 гривня 2003 отримано 101 різну текстуру для 0–100%; повторно згенеровані 65% побайтово тотожні.
- Помилок JavaScript під час цих сценаріїв немає. Вручну переглянуто знімки картки, довільного повороту й зворотного боку; напис на звороті не віддзеркалений.

## Межі перевірки

Це браузерна емуляція мобільного вікна й сенсорних подій, а не вимірювання FPS на фізичному телефоні. Моделі й рельєф залишаються стилізованими; це не скан монет. Canvas-резерв має простіше освітлення. Формат збережень не змінено; нові поля стану в резервній копії не потрібні.
