## Перевірки

`npm run check`: шість наборів пройдено. Збережено попередні перевірки ID, цін, нагород, резервних копій, виїздів, очищення та обертання. Новий `tests/content-check.cjs` перевіряє порядок готових / поточних / отриманих цілей, незмінність даних при сортуванні, одноразову виплату й збереження після перезапуску, доступність нагород лише в таборі, видимість скидання стану, дії інвентарю та підтвердження / скасування повернення.

Браузерні перевірки виконано у Chromium, локально, на окремих тестових збереженнях:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium node tests/content-browser.cjs
PLAYWRIGHT_MODULE=/path/to/playwright CHROMIUM_PATH=/path/to/chromium node tests/inspection-browser.cjs
```

- Шість екранів: табір, рюкзак, майстерня, колекція, щоденник, пошук; ширини 320, 390, 768 px — без горизонтального переповнення.
- Картка знахідки: 320×568, 390×844, 412×915 та 844×390 — пропорції та підпис без перекриття.
- Отримання готової нагороди у верхній картці, переміщення в отримані, правильна сума купонів, відновлення після перезапуску.
- Мініатюра шайби справді намальована після появи картки; кнопки альбому для сміття та дії нульових запасів відсутні.
- Кнопка скидання ракурсу з’являється після обертання всередині зображення та зникає після скидання.
- Збережені сенсорне обертання, стан відкритої знахідки після перезапуску, незалежність порівняння від збереження, 101 відмінний вигляд монети та відтворюваність її текстури.
- Помилок JavaScript під час цих сценаріїв немає.
- Візуально переглянуто порівняльний аркуш 16 моделей, картку шайби у стані 27%, щоденник з готовою нагородою та рюкзак із мініатюрами.

## Межі

Перевірка мобільних розмірів і сенсорних подій проводиться у браузері, не на фізичному Android-пристрої. Моделі залишаються стилізованими, а не фотограмметричними; мікровідмінності штемпелів монет не відтворюються. Кількість контенту, числові ID, економіку та формат збереження не змінено.
