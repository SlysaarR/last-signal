# Перевірка якості 0.31.0

Дата: 13.10.2026. Базова версія: 0.30.0, коміт b5a1a0f69b2483d2ad12255af3003ec8c33aaa85.

## Виправлені сценарії

- Пошук: 60 подій руху до наступного кадру викликають одне оновлення показників. Поле не запускає рендер табору, майстерні, інвентарю, журналу й колекції.
- Очищення: частковий і завершений прогрес проходять згортання, перезапуск, експорт та імпорт без повторного списання енергії чи дублювання знахідки.
- Збереження: некоректний JSON, невідома версія, невалідні ID та пошкоджений журнал не замінюють початковий запис новою грою. Коректний імпорт знімає блокування запису.
- Сумісність: старі каталожні ID перевіряються за попереднім контрольним хешем; збережено попередній ключ і оболонку version 1. Нове поле очищення необов’язкове.
- Керування: другий вказівник не переміщує котушку; втрата захоплення завершує жест; вікна огляду і відновлення блокують копання.
- Каталог: усі картки відкриваються; три ракурси монет повертаються до початкового виду, клавіатурне перевертання не змінює дані гри. Прикраси й реліквії використовують уже наявні малюнки.
- Звіт: оглянуті предмети відокремлено від вмісту рюкзака; взяті з дому речі не названо новою здобиччю. Пропущені лічильники дуже старого виїзду не псують збереження при поверненні.

Команда відтворення: `npm run check`. Це перевірки модулів у Node з тестовим DOM; вони не вимірюють FPS і не замінюють запуск на Android.

## Модель напрямків

Команда: `npm run balance`. 2 000 ділянок на кожну комбінацію 4 напрямків і 3 рівнів спорядження: разом 24 000. Випадковість відтворювана.

Умови: усі три предмети спорядження мають указаний рівень, напрямки вважаються відкритими, рюкзак на початку порожній, енергія повна, їжі немає. Модель ідеально знаходить цілі без порожніх ямок, пропускає непосильні розкопки й залишає найдорожчі речі. Результат — продаж усього відібраного мінус дорога. Це оптимістична модель, а не фактичний дохід людини: немає часу пошуку, помилок наведення, покупок спорядження та предметів, залишених у колекції.

Водний напрямок найвигідніший для купонів у цій моделі: прикраси дорогі, неглибоких сигналів більше. На першому рівні прикраси становлять близько 20.5% оглянутих предметів проти 5.0% за містом; реліквії — 1.4% проти 9.8%. Це різні цілі поїздок, а не доказ рівноцінності економіки. Далекі дороги дають вищу частку монет, а звичайний напрямок лишається дешевим способом відвідати всі місцевості.

Ціни та таблиці випадкових знахідок у 0.31 не змінено. Однієї оптимістичної моделі недостатньо для довільного зниження винагород водного напрямку; перевагу за купонами зафіксовано для подальшого ігрового спостереження. Шанси бідної / звичайної / вдалої ділянки залишаються 25 / 65 / 10%; коштовна дорога не гарантує знахідку.

## Межі перевірки

- Історичну й нумізматичну точність усіх схем не перевірено заново за зовнішніми джерелами. Каталог і художні схеми не змінювалися.
- Локальний Chromium у середовищі відсутній, а завантаження браузера недоступне. Візуальний стан опублікованої версії перевіряється окремо; повний сенсорний прогін на фізичному Android ще потрібен.
