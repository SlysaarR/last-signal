# Останній сигнал — ціль релізу 1.0

Оновлено 2026-10-14. Поточний етап: **розробка, 0.50.0; до магазинного релізу ще не готово**.

Мета Влада: повноцінна гра, яку не соромно випустити в Google Play або Steam. Пріоритет — якість завершеного ігрового циклу, оптимізація, збереження довгої прогресії й сумісність із наявним прогресом. Новий контент додається, коли він закриває конкретну прогалину гри.

## Що має отримати гравець

- Зрозумілий перший виїзд без пояснень автора; усі дії доступні дотиком і мишею/клавіатурою.
- Повний цикл: підготовка → вибір місця → пошук → розкопка → огляд → рішення про знахідку → табір → альбом/продаж → розвиток.
- Довга мотивація: кар’єра, замовлення, набори монет, нові напрямки й 27 покупок спорядження. Порожні ями та бідні ділянки лишаються частиною пошуку, але не створюють безвиході.
- Надійне продовження гри після закриття, оновлення й офлайн-сеансу. Відновлення через резервну копію без втрати оригіналу при помилці.
- Читабельний інтерфейс, передбачуване керування та виміряна швидкодія на заявлених пристроях.

## Послідовність роботи

1. **Вхід і стабільність (0.50):** навчання, довідка, регресії в CI, облік невирішених прав. Завершення визначається перевірками та плейтестом першого виїзду.
2. **Оптимізація й подача:** усунути повільний програмний 3D-рендер, перевірити слабший Android і ПК, довести великі екрани, фокус, масштаб тексту й меню.
3. **Завершеність проходження:** пройти кар’єру й оцінити нагороди/витрати/варіативність. Закривати підтверджені провали; не скорочувати прокачку без рішення Влада. Паралельно замінити або документально очистити права на фото.
4. **Кандидат 1.0:** зафіксувати контент, підготувати платформну збірку, документацію даних/підтримки й магазинні матеріали; прогнати матрицю нижче на самій збірці.
5. **Тестовий випуск:** зовнішні тестувальники, виправлення критичних помилок, повторні тести оновлення. Тільки після цього ставити 1.0 і подавати готовий пакет на перевірку магазину.

Android — робочий перший орієнтир через нинішній мобільний інтерфейс. Це не остаточний вибір магазину. Steam потребує зручної самостійної ПК-збірки та окремої перевірки; контролер і Steam Deck поки не заявляються.

## Вимоги платформ — перевірено 2026-10-14

- Для особистих Google Play-акаунтів, створених після 13 листопада 2023 року, перед заявкою на доступ до production потрібен закритий тест: щонайменше 12 учасників безперервно протягом 14 днів. Тип і дата акаунта Влада невідомі. [Офіційна довідка](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en).
- Google Play вимагає форму Data safety та посилання на політику приватності й для застосунків, які не збирають дані; internal-only track має виняток. Заповнювати за **фінальною збіркою**, включно з оболонкою й SDK. [Офіційна довідка](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en).
- Для Steam потрібні належні права на контент; готові сторінка магазину та збірка проходять перевірку. [Onboarding](https://partner.steamgames.com/doc/gettingstarted/onboarding), [Review Process](https://partner.steamgames.com/doc/store/review_process).

Перед фактичною подачею перевірити актуальні вимоги цільового API, пакета, підпису, рейтингу та сторінки саме вибраного магазину. Цей файл не стверджує, що пройдено модерацію, юридичну перевірку або сертифікацію.

## Команди і межі доказів

`npm run check` — функціональні/регресійні перевірки та точність офлайн-пакета. GitHub workflow **Game quality** запускає їх для main і PR. Це не встановлює захист гілки й не блокує GitHub Pages автоматично.

`npm run audit:assets` — цілісність переліку фотографій/джерел/хешів; повідомляє невирішені права. `npm run release:check` додатково вимагає документованих дозволів для фотографій і **зараз очікувано завершується помилкою**. Навіть зелений результат не замінить усі умови таблиці.

У поточному середовищі немає дозволеного браузерного QA та фізичних пристроїв. Node VM/native Canvas перевіряють код і графічні функції, але не доводять фактичну зручність, звучання, жести чи FPS. Не позначати ці перевірки виконаними за скриншотом, згенерованим макетом або симуляцією.
